## Deploy to GitHub Pages

1. Create a new GitHub repository named `redacted` (or whatever you want the URL to be)
2. Upload all files: `index.html`, `style.css`, `script.js`
3. Go to **Settings → Pages**
4. Under **Source**, select `Deploy from a branch`
5. Choose `main` branch, `/ (root)` folder
6. Click **Save**

Your site will be live at:
`https://yourusername.github.io/redacted/`

Or if you want it at the root of your GitHub profile:
- Name the repo `yourusername.github.io`
- Site will be at `https://yourusername.github.io`

## Customise

- **Excerpts** — edit the `.excerpt-block` sections in `index.html`
- **ARC team link** — replace `href="#"` in the readers section with your signup form link (Google Form, Typeform, etc.)
- **Amazon / Goodreads** — replace `href="#"` with real links when ready
- **Fragments** — add more `.excerpt-block` divs as you write
